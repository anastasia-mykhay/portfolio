# Портфоліо

## Проєкт і стек

Портфоліо UI/UX-дизайну: головна (hero, проєкти, контакт) і, за планом, сторінка на кожен проєкт (ще не зроблені, структуру не вирішено). Тексти сайту лише англійською. Факти про проєкти (ролі, статуси, тестування) бери з плану сайту, не вигадуй.

- Next.js 16 (App Router, `cacheComponents`), React 19, TypeScript, Tailwind CSS 4, Storybook 10. Імпорти через `@/`.
- `app/`: сторінки (`page.tsx`) і секції головної (`ProjectsSection.tsx`, `SiteFooter.tsx`), `layout.tsx`, `globals.css` (токени), `fonts.ts`.
- `components/`: компоненти, поруч історії `*.stories.tsx`. `stories/Tokens.mdx`: сторінка токенів.
- `assets/`: картинки. Їх імпортують (`import miriHome from "@/assets/miri-home.png"`) і показують через `next/image`. Виняток: `app/favicon.ico`.
- Команди: `npm run dev` (сайт, порт 3000), `npm run lint`, `npm run build` (спершу Storybook у `public/storybook`, потім сайт: збірка Next.js з перевіркою типів), `npm run storybook`, `npm run build-storybook`. Тестів немає.

## Кольори

Токени `--color-*` у блоці `@theme` в `app/globals.css` (джерело всіх значень). Назви за роллю, не за кольором. Приклади класів: `bg-canvas`, `text-text`, `border-line`.

- `canvas`: фон сторінки. `canvas-dark`: фон hero, футера й плашок.
- `text`: основний текст на `canvas` і весь текст на картках проєктів.
- `text-on-dark`: текст на темному фоні й на плашках.
- `text-muted`: приглушений текст і неактивні номери на `canvas`. `text-muted-on-dark`: приглушений текст на темному.
- `line`: розділювачі на світлому й неактивні крапки рейки. `line-dark`: розділювачі на темному.
- `project-miri`, `project-rentflow`, `project-studio`, `project-sema` (`bg-project-miri`): лише заливки й маркери, ніколи не для тексту на `canvas`. На картках текст завжди `text`, не `text-on-dark`.
- `link-hover` (той самий колір, що `project-miri`): ховер посилань на темному фоні.
- Лінія над ролями в картці: колір тексту на 35% (`border-text/35`).

## Типографіка

Шрифт `font-sans`: Archivo (`next/font`, `app/fonts.ts`), запасний Arial. Кирилиці в Archivo немає (піде на Arial), `cyrillic` у `subsets` ламає збірку. Курсив 200 лише для слова «AI-assisted». `body` уже має `bg-canvas font-sans text-body text-text`.

Один клас (`text-display-xl`) задає розмір, висоту рядка, трекінг і жирність: не додавай поверх `leading-*`, `tracking-*`, `font-*` чи інший розмір. `display-*` і `email` самі ростуть із шириною вікна: пікселі й `md:text-…` для них не став.

| Клас | Де використовувати |
| --- | --- |
| `text-display-xl` | заголовок hero |
| `text-display-l` | заголовок «Projects» |
| `text-display-m` | назва картки |
| `text-display-s` | підзаголовок картки й окремий підзаголовок на сторінках кейсів |
| `text-email` | лише email у футері: 20–84 px, трекінг -0.03em; підібраний, щоб адреса на 26 символів стояла в один рядок |
| `text-body` | основний текст |
| `text-label` | мітки: меню, мета картки, нижні смуги |
| `text-label-strong` | назви «Question» і «Decision» у картках |
| `text-small` | плашки |

Великі літери для `label` і `label-strong` додає компонент або секція класом `uppercase`: у стиль вони не входять.

## Відступи, радіуси, пропорції, сітка та інші токени

- **Відступи**: окремих токенів немає, лише 9 кроків: `1, 2, 3, 4, 6, 8, 10, 12, 16` (4–64 px). Інші (`5`, `7`, `14`) не використовуй. `0` для скидання відступу дозволений (`lg:mt-0`).
- **Радіуси**: `rounded-control` (плашки й круглі елементи), `rounded-card` (картки, прямі кути), `rounded-image` (скріншоти).
- **Тінь**: `shadow-screen`, для скріншотів.
- **Пропорції**: токенів `--aspect-*` немає. Скріншоти в природних пропорціях, без обрізання й розтягування.

**Розкладка сторінки** (лише в сторінках і секціях в `app/`, у `components/` ніколи):

- `max-w-page` (1232 px): ширина вмісту.
- `--spacing-section` (64 px): відстань між великими секціями (`gap-section`, `pt-section`, `py-section`).
- `lg:w-rail` (`--container-rail`, 120 px): лише колонка `ProjectRail`, для інших елементів не бери.

Секції головної мають бічні поля `px-6` на зовнішньому елементі, а всередині `mx-auto w-full max-w-page`.

**Крапки, кільця й рух** (кожен лише за своїм призначенням):

- `size-dot` (10 px), `size-ring` (крапка + 8 px): лише розмір крапок і кілець, не відступи (`p-dot`, `gap-ring`).
- `translate-y-ring-travel`: лише шлях кільця. `ease-ring`: лише крива руху кільця.

**Сітка** (спільної для сайту немає, у кожної секції своя; breakpoints стандартні: `md` 768, `lg` 1024, `xl` 1280):

- Hero: абзаци до `md` колонкою «сходинками», від `md` сітка 12 колонок, від `lg` ще 4 рядки; на `xl` лише поправки зсувів і полів.
- Projects: до `lg` рейка рядом зверху, картки в одну колонку; від `lg` рейка стовпчиком ліворуч, картка має 2 колонки, бік скріншота чергується, картки однакової висоти.
- Футер: колонок немає.

## Компоненти

Лежать у `components/`. Бери готовий замість нового. Пропси, поведінка й приклади: у Storybook. Стану disabled і полів форм у проєкті зараз немає.

| Компонент | Для чого | Варіанти й стани |
| --- | --- | --- |
| `BackToTop` | кнопка «Back to top», лише у футері на `canvas-dark` | default, hover, focus-visible, коротко після кліку (кільце вгорі) |
| `NavLink` | посилання меню у верхній смузі hero, лише на `canvas-dark` | default, hover, focus-visible |
| `Pill` | плашка-тег на картках проєктів | один варіант, неінтерактивна |
| `Marker` | декоративна крапка-маркер перед текстом | `hollow`, `filled`; неінтерактивна |
| `RoleItem` | пункт картки проєкту: крапка, назва, текст («Question», «Decision») | крапка `hollow` або `filled`; неінтерактивний |
| `ProjectRail` | рейка проєктів (`nav`, пункти й одне кільце), лише на `canvas` | кільце біля поточного пункту або приховане; до `lg` ряд, від `lg` стовпчик |
| `ProjectRailItem` | пункт рейки: кнопка з крапкою й номером, лише на `canvas`; колір задає проп `project` | default, current, hover, focus-visible |

- На сторінці бери `ProjectRail`, не пункт окремо: без кільця поточний пункт видно лише за кольором. Ширину пункту задає батьківський елемент.
- `ProjectRail` сам стежить за елементами з `targetId` і прокручує до них. Сторінка задає лише місце: ширину колонки, відстані, sticky, ряд на всю ширину, відступ прокрутки карток. `className` лише для цього.

## Правила

- Мій дизайн і узгодженість сайту важливіші за зручність коду. Спочатку відтвори дизайн наявними токенами, компонентами й правилами. Лише якщо так не виходить, поясни простими словами, що саме відрізнятиметься, покажи варіанти й спитай мене. Не змінюй дизайн і не погіршуй його мовчки. Мій дозвіл на виняток діє тільки для названого місця й не поширюється на інші; нове загальне правило додавай лише з моєю окремою згодою.
- Кольори, розміри тексту й радіуси лише з `@theme`. `text-white`, `bg-black`, `text-sm`, `rounded-lg` мовчки нічого не дають. `rounded-full`, стандартні тіні (`shadow-lg`) й пропорції (`aspect-video`) спрацюють, але їх не використовуємо.
- Виняток: `max-w-xs` лише для другого абзацу hero (`app/page.tsx`), для інших елементів не використовуй.
- Довільні значення в квадратних дужках (`p-[13px]`, `h-[150px]`, `text-[#fff]`) заборонені.
- Якщо токена бракує, спитай мене. Нових кольорів і токенів без моєї згоди не додавай.
- Нових елементів, яких немає в моєму дизайні, не вигадуй. Тимчасові заглушки й пробні стани в коді (позначені `ТИМЧАСОВО`, «Screens in progress», текст замість email) не є частиною дизайн-системи: не копіюй їх.
- Кожен інтерактивний елемент має видимий `focus-visible`; hover та інші стани роби за макетом.
- Якщо зʼявиться вимкнена кнопка, вона використовує `aria-disabled` із поясненням; поле форми повинно мати стан помилки.
- Після зміни компонента в тому ж кроці онови його історію й документацію (скіл `storybook`; якщо він суперечить CLAUDE.md, головний CLAUDE.md). Новий компонент: історія, docs і, за моєю згодою, рядок у «Компонентах».
- Після зміни токенів перевір `stories/Tokens.mdx` і цей файл та перезапусти `npm run dev`.

## Доступність і перевірка

- Контраст тексту: щонайменше 4.5 : 1, великого 3 : 1 (пари в Storybook, Foundations/Tokens).
- Контур фокуса: `focus-visible:outline-2` і відступ; колір `outline-text-on-dark` на темному, `outline-text` на світлому.
- Зменшений рух: переходи вимикай `motion-reduce:transition-none`; прокрутку з коду з `prefers-reduced-motion` роби `instant`.
- Змістовні картинки мають англійський `alt`; декоративні елементи `aria-hidden="true"`. `nav` має `aria-label`.
- Перед завершенням змін коду обовʼязково `npm run lint` і `npm run build`, обидва без помилок. Після змін вигляду переглянь на 320, 375, 768, 1024 і 1280 px.
- Також перевір: Tab показує контур фокуса; у змінених файлах немає класів поза правилами. Чого не бачив сам, не стверджуй.
